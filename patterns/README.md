# Anchor Drift Taxonomy

These documents define the theoretical classification system used by Anchor's Architectural Drift Engine.

The pattern documents are intended for researchers, auditors, maintainers, and contributors interested in the rationale behind Anchor's verdict generation.

These files are explanatory references and are not executed by the Anchor runtime.
